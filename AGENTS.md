# Ändra briefingbilder tillsammans

1. Utgå från aktuell `main` och använd en egen branch eller worktree för varje uppgift.
2. Öppna en PR mot `main`. Beskriv berörda flöden och filer, vad som verifierats och eventuella nästa steg. Länka till en relaterad PR om samma kod redan ändras där.
3. Om flera uppgifter berör samma funktion, samordna ändringarna i den befintliga PR:n eller låt den första landa innan den andra fortsätter.
4. Lägg nya bilder i rätt datummapp med beskrivande filnamn. Behåll befintliga filsökvägar eftersom de kan vara länkade från äldre briefingar.
5. Kontrollera att bilderna öppnas och att innehållet kan publiceras. Repot är publikt.
